# ГеоСуши

Интерактивный гастрономический атлас роллов с географическими названиями. Карта связывает блюда с местами, давшими им имя, и показывает историю, состав и фотографии роллов.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовые статические файлы появятся в каталоге `dist/`.

Сайт: [geosushi.ru](https://geosushi.ru)
